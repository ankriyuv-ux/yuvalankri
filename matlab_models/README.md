# MATLAB model archive

This folder contains the MATLAB scripts developed for the PhD model during the current work cycle (September 2026). It includes SOC/exchange controls, anisotropy scans, Full-XYZ and Bz-only LLG comparisons, and the N=14 half-filling baseline.

Notes:
- Older/versioned scripts are intentionally preserved for reproducibility.
- `hf14.m` is the short-name N=14 half-filling baseline (SOC=0, Ku=0, J0=0 vs 150 meV, Full XYZ).
- Some scripts are diagnostic or intermediate versions; compare comments at the top of each file before use.
